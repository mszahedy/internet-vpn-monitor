# Internet VPN Monitor

A simple Python tool for monitoring internet connectivity and recording outages.

## Features
- Connection monitoring
- Response time measurement
- Automatic outage logging
- CSV report generation
- Configurable monitoring interval

## Requirements
- Python 3.8+
- Internet connection

## Installation

git clone https://github.com/mszahedy/internet-vpn-monitor.git

cd internet-vpn-monitor

## Run

python monitor.py
